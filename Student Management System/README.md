# Student Management System

A simple Student Management System built using **Node.js, Express.js, EJS, and MongoDB**. The application allows users to add, view, edit, and delete student records.

## Features

- Add new student records
- View all students
- Edit student details
- Delete student records
- MongoDB database integration
- EJS-based user interface
- Express.js routing

## Tech Stack

- Node.js
- Express.js
- EJS
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:  
   `git clone https://github.com/stutigupta1503/DecodeLabs-Internship.git`

2. Navigate to the project:  
   `cd DecodeLabs-Internship`  
   `cd "Student Management System"`

3. Install dependencies:  
   `npm install`

4. Start the server:  
   `node index.js`

5. Open your browser and visit:  
   `http://localhost:3000`

## CRUD Operations

- **Create:** Add new student records.
- **Read:** View all student records.
- **Update:** Edit existing student details.
- **Delete:** Remove student records.
